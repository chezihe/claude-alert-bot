# Quick Task 260508-001: Claude Code icon + bounce animation

## Goal
WidgetIconView를 SF Symbol 플레이스홀더(`bell.badge.fill`)에서 실제 Claude Code 주황색 아이콘으로 교체하고, 위아래 통통 튀는 애니메이션을 추가한다.

## Source asset
- 사용자 다운로드: `~/Downloads/claudecode-color.svg` (24×24 viewBox, fill `#D97757`, 픽셀아트풍 로봇 글리프)

## Tasks

### Task 1 — Asset catalog 추가
- **files:** `App/Assets.xcassets/Contents.json`, `App/Assets.xcassets/ClaudeCodeIcon.imageset/Contents.json`, `App/Assets.xcassets/ClaudeCodeIcon.imageset/claudecode-color.svg`
- **action:** 새 asset catalog 생성. `ClaudeCodeIcon` imageset에 SVG 파일 등록. `preserves-vector-representation: true` + `template-rendering-intent: original` (원본 색상 유지).
- **verify:** `xcodegen generate`가 catalog를 자동 인식하고 빌드 산출물의 `Assets.car`에 포함됨.
- **done:** `find …/ClaudeAlertBot.app/Contents/Resources -name Assets.car` 결과가 1개.

### Task 2 — WidgetIconView 갱신
- **files:** `App/WidgetIconView.swift`
- **action:**
  - `Image(systemName: "bell.badge.fill")` → `Image("ClaudeCodeIcon").resizable().aspectRatio(contentMode: .fit)`로 교체. 36×36 내부 프레임 + 44×44 외부 프레임 유지.
  - `@State private var bounceOffset: CGFloat = 0` + `.offset(y: bounceOffset)` + `.onAppear { withAnimation(.easeInOut(duration: 0.45).repeatForever(autoreverses: true)) { bounceOffset = -5 } }`로 점프 애니메이션 추가.
  - `@Environment(\.accessibilityReduceMotion)` 가드로 시스템 "동작 줄이기" 설정 시 애니메이션 비활성화.
  - 헤더 주석을 새 동작에 맞춰 갱신 (D2-12 SF Symbol 자리표시자 메모 제거).
- **verify:** `xcodebuild test` 79/79 통과.
- **done:** 빌드 성공 + 테스트 모두 통과.

## Decisions
- **Bounce amplitude:** 5pt (44pt 컨테이너 안에 36pt 아이콘 → 위쪽 여유 4pt, 1pt만 살짝 넘어가는 정도라 자연스럽게 "통통" 느낌).
- **Duration / curve:** 0.45s easeInOut, autoreverses, repeatForever. "통통"의 리드미컬한 느낌에 맞춤.
- **Continuous vs one-shot:** 위젯은 작업 완료 시에만 표시되고 사용자가 클릭할 때까지 잔존하므로(코어 가치) **계속 튀는 방향**이 맞음.
- **Reduce Motion 존중:** 접근성 기본 매너. 2줄 추가로 처리.
- **Badge 영향:** 바운스는 Image에만 적용 → ZStack의 +N 배지는 topTrailing 앵커에 고정 유지.
