# Quick Task 260508-002: Popover unavailable-session UI

## Goal
세션 목록(팝오버)의 디자인 톤을 미니멀로 락인하면서, **닫힌 iTerm2 세션**에 대한 UI surface를 미리 깔아둔다. 실제 라이브 검증은 Phase 3 ITermBridge가 담당.

## Tone lockdown
- **카피:** 미니멀 영어, "session" 용어 통일 (`Session unavailable`)
- **시각:** 행 전체 opacity 0.5, 트레일링 영역에 보조 회색 텍스트로 라벨
- **클릭 가능 유지:** 닫혔어도 알림 정리는 가능 (D2-08 click contract 그대로)
- **드롭한 옵션:** 컬러 dot, ✨ 반짝임, 이모지(👻), 마지막 메시지 미리보기(transcript 파싱 필요 → Phase 4+)

## Tasks

### Task — UI surface 추가
- **files:** `App/PopoverContentView.swift`, `App/PopoverRowView.swift`, `ClaudeAlertBotTests/PopoverContentTests.swift`
- **action:**
  - `PopoverContentRules.isUnavailable(sessionID:in:)` 순수 함수 추가
  - `PopoverContentRules.unavailableLabelText` 상수 락 (`"Session unavailable"`)

  - `PopoverRowView.isAvailable: Bool = true` 파라미터 추가 — false일 때 트레일링이 라벨로 교체 + 행 opacity 0.5 + accessibilityLabel 분기
  - 디폴트 인자 덕분에 `WidgetPopoverController` 호출부 무변경
  - 테스트 3개 신규: 멤버십 체크, 빈 셋, 카피 락
- **verify:** `xcodebuild test` 82/82 통과 (기존 79 + 3 신규).
- **done:** 빌드 + 테스트 모두 통과.

## Decisions
- **모델/디스크 스키마 변경 없음:** `CompletedSession.isAvailable` 같은 필드 추가 안 함. unavailable 상태는 ephemeral (앱 재시작 시 재시도 여지). `WidgetPopoverController`가 in-memory `Set<String>`만 들고 있게 됨.
- **카피 락 테스트:** 미니멀 영어 톤이 미래에 표류하지 않도록 `unavailableLabelText` 값을 verbatim으로 assert (T-COPY-DRIFT-01과 동일 패턴).
- **클릭 동작 유지:** 닫힌 세션도 클릭하면 그대로 dispatch — 사용자 선택권 유지. Phase 3가 점프 시도→실패→ unavailable 표시 사이클을 마무리.
- **D2-06/D2-16 우회 안 함:** unavailable일 때 time suffix와 orphan `?`는 숨기지만, 데이터 자체는 그대로. 다시 available로 돌아오면 표시 복귀.

## Out of scope
- 실제 라이브 검증 / `unavailableSessionIDs` populate — Phase 3 ITermBridge.
- 마지막 메시지 미리보기 (`transcript_path` JSONL 파싱) — Phase 4+ 데이터 작업 동반.
- 컬러 dot, 상대시간 한국어화, 반짝임 등 장식 요소 — 미니멀 톤 락업에 따라 보류.
